# tee-app

## Working together

1. Clone the repo:
   ```bash
   git clone https://github.com/ernestniemann-a11y/tee-app.git
   cd tee-app
   ```
2. Before you start working, get the latest changes:
   ```bash
   git pull
   ```
3. Make a branch for your work:
   ```bash
   git checkout -b my-feature
   ```
4. Commit and push it:
   ```bash
   git add .
   git commit -m "Describe what you changed"
   git push -u origin my-feature
   ```
5. Open a Pull Request on GitHub so the other person can review it and merge it into `main`.
